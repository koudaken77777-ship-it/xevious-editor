# レトロゲームファンオリジナル ゼビウスエディッタ

ファミコン版『ゼビウス』の面（地形・敵・イベント）を編集できる、ブラウザで動くマップエディッタです。
作った面は改造ROMやIPSパッチとして保存でき、内蔵エミュレーターですぐにテストプレイできます。

- 現在の版：**正式版 Ver1.17**
- 作者：[レトロゲームファン（YouTube）](https://www.youtube.com/@RETROGAME77)

## 使い方

### Web版（おすすめ・常に最新）
次のURLを開くだけで使えます。インストールは不要です。

https://koudaken77777-ship-it.github.io/xevious-editor/

### ダウンロード版
**[最新版のダウンロードはこちら](https://github.com/koudaken77777-ship-it/xevious-editor/releases/latest)**
「Assets」にある html ファイルをダウンロードし、ダブルクリックでブラウザから開いてください。インターネットにつながっていなくても動きます。
各版の変更点も同じページで確認できます。

## はじめに必要なもの
- **ファミコン版ゼビウスの純正ROM（.nes）**
  起動後に一度読み込ませてください。ROMはこのエディッタには**含まれていません**。各自で用意してください。

## 推奨環境
- パソコンのブラウザ（Chrome / Edge 推奨）
- 画面の横幅 1280px 以上
- 文字が小さい・大きいときは、ブラウザの表示倍率（Ctrl + マウスホイール）で調整してください

## 安心して使えるように
- ブラウザの中だけで動きます。インストールや、レジストリ・パソコンの設定の変更は一切しません。
- 読み込んだROMや作った面は、お使いのブラウザの中にだけ保存されます。外部へ送信することはありません。
- インターネットにつながるのは、次のときだけです。
  - YouTubeへのリンクと「不具合を報告」ボタン（Googleフォーム）を押したとき
  - **更新確認**（ダウンロード版のみ）：起動時（12時間に1回まで）と「🔄 更新確認」ボタンを押したときに、GitHubから最新版の版番号と変更点を読み込みます。こちらから送るものはありません。自動での確認は、確認画面のチェックを外すと止められます。

## 新しい版が出たとき
- **Web版**：開き直すだけで最新版になります。
- **ダウンロード版**：起動時に「新しい版が出ています」と変更点が表示されます。「⬇ 今すぐダウンロード」を押すと新しいファイルがダウンロードされます（Ver1.5 をお使いの場合は「ダウンロードページを開く」から）。作りかけ面や純正ROMの登録はそのまま引き継がれます（同じブラウザで、ファイルとして開いている場合）。

## 保存データについて
作りかけ面や純正ROMの登録は、**開き方（Web版／ダウンロード版）やブラウザごとに別々に保存**されます。
別の開き方へ移るときは、「ファイル」タブの「📦 全部をファイルへ」で書き出し、移った先で「📥 ファイルから追加」で読み込んでください。

## 不具合の報告
エディッタ右上の「🐞 不具合を報告」ボタンから送ってください。

## 注意
- 『ゼビウス』は株式会社バンダイナムコエンターテインメントの著作物です。本エディッタは非公式のファン制作ツールであり、同社とは関係ありません。
- 作った改造ROMの配布はせず、共有するときはIPSパッチで行ってください。
